> ⚠️ **This repository is source-available but not open source.**

Vielen Dank für dein Interesse am Projekt **PrescriptCheck**!  
Thank you for your interest in **PrescriptCheck**!

---

## Wer darf beitragen? / Who Can Contribute?

Dieses Repository ist **nicht öffentlich zur freien Mitarbeit** freigegeben. Beiträge sind nur möglich für:  
This repository is **not open for public contributions**. Contributions are only accepted from:

- Autorisierte Mitglieder des AT Medical Teams / Authorized members of the AT Medical team
- Vertragspartner mit schriftlicher Genehmigung / Contract partners with written authorization
- Externe Mitwirkende nach ausdrücklicher Einladung durch AT Medical GmbH / External contributors by explicit invitation from AT Medical GmbH

Für Anfragen zur Mitwirkung wende dich an: **support@at-medical.de**  
To request contributor access, contact: **support@at-medical.de**

---

## Möglichkeiten zur Mitwirkung / How to Contribute

Autorisierte Mitwirkende können:  
Authorized contributors may:

- Fehler melden (Issues) / Report bugs
- Code optimieren (Pull Requests) / Improve code
- Neue Funktionen vorschlagen / Suggest new features
- Sicherheit verbessern / Help improve security
- Dokumentation ergänzen / Improve the documentation

---

## Entwicklungsrichtlinien / Development Guidelines

1. Erstelle einen Feature-Branch vom aktuellen `main`:  
   `git checkout -b feature/meine-änderung`  
   `git checkout -b feature/my-feature`
2. Führe deine Änderungen durch und committe sie:  
   `git commit -m "Neue Funktion hinzugefügt"`  
   `git commit -m "Added new feature"`
3. Push den Branch und erstelle einen Pull Request:  
   `git push origin feature/meine-änderung`  
   `git push origin feature/my-feature`
4. Pull Requests werden ausschließlich durch AT Medical GmbH reviewed und gemergt.  
   Pull requests are reviewed and merged exclusively by AT Medical GmbH.

---

## Code-Stil / Code Style

- Verwende **ESLint** (Konfig liegt im Projekt)  
  Use ESLint for linting
- Einrückung: 2 Leerzeichen / Indentation: 2 spaces
- Schreibe selbsterklärenden Code / Write self-explanatory code
- Commit-Messages im Klartext / Use clear commit messages
